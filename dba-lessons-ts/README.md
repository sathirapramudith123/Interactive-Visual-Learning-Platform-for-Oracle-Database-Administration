# DBA Visual Lessons (TypeScript)

Animated step-by-step Oracle DBA lessons (IT4040). Vite + TypeScript.

    npm install
    npm run dev      # http://localhost:5173
    npm run build    # type-check + production build in dist/

Add a lesson: edit `src/lessons.ts` (copy a lesson block). Deploy: import the repo in Vercel (Vite is auto-detected).
